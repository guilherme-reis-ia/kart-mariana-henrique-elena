# Mariana, Henrique e Elena — Kart 2D

Jogo de corrida de kart visto de cima, feito com HTML5, JavaScript puro e Canvas 2D.
Sem frameworks, sem bibliotecas, sem instalação.

## Como rodar

Abra o arquivo `index.html` no Chrome (duplo clique). Não precisa de servidor.

## Estado atual

Em construção, por marcos. Marco 2 concluído: um kart controlado pelo teclado
(setas ou WASD) na pista oval, com grama, muro, câmera e 3 voltas validadas
por setores (C mostra os setores, R reinicia).

O README completo, com instruções para criar pistas, vem no marco 6.
