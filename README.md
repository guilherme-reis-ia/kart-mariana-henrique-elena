# Mariana, Henrique e Elena — Kart 2D

Jogo de corrida de kart visto de cima, feito com HTML5, JavaScript puro e Canvas 2D.
Sem frameworks, sem bibliotecas, sem instalação.

## Como rodar

Abra o arquivo `index.html` no Chrome (duplo clique). Não precisa de servidor.

## Estado atual

Em construção, por marcos. Marco 5 concluído: 3 fases (Oval da Largada,
Serpente de Grama e Trilha do Óleo), com grama, óleo, turbo e drift.
Chegar em 1º ou 2º libera a próxima fase (o progresso fica salvo no
navegador). Controles: setas ou WASD para dirigir, Espaço para drift;
C mostra os setores, R reinicia, Esc volta.

Também dá para jogar online: https://guilherme-reis-ia.github.io/kart-mariana-henrique-elena/

O README completo, com instruções para criar pistas, vem no marco 6.
